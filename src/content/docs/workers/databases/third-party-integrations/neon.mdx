[Neon](https://neon.tech/), tamamen yönetilen sunucusuz PostgreSQL'dir. Depolama ve hesaplamayı ayırarak sunucusuz, dallanma ve dipsiz depolama gibi modern geliştirici özellikleri sunar.

:::note

Neon'a [Hyperdrive](/hyperdrive) (önerilen) kullanarak veya Neon sunucusuz sürücüsü `@neondatabase/serverless` kullanarak bağlanabilirsiniz. Her ikisi de bağlantı havuzlama sağlar ve Workers'dan veritabanınıza güvenli bir bağlantı oluşturmak için gereken gidiş-dönüş miktarını azaltır.

Hyperdrive, veritabanı bağlantı kurulumunu ve bağlantı havuzlamasını Cloudflare ağı boyunca gerçekleştirdiği için mümkün olan en düşük gecikmeleri sağlayabilir. Hyperdrive yerel veritabanı sürücülerini, kütüphanelerini ve ORM'leri destekler ve tüm [Workers planlarında](/hyperdrive/platform/pricing/) dahildir. [Hyperdrive'un Nasıl Çalıştığı](/hyperdrive/configuration/how-hyperdrive-works/) hakkında daha fazla bilgi edinin.

:::

`@neondatabase/serverless` kullanarak Neon'a bağlanmak için şu adımları izleyin:

1. Bağlanmak için mevcut bir Neon veritabanına sahip olmanız gerekir. [Neon veritabanı oluşturun](https://neon.tech/docs/postgres/tutorial-createdb#create-a-table) veya [mevcut veritabanından Neon'a veri yükleyin](https://neon.tech/docs/import/import-from-postgres).

2. Neon SQL editörünü kullanarak bir `elements` tablosu oluşturun. SQL Editörü, veritabanlarınızı doğrudan Neon Console'dan sorgulamanıza olanak tanır.

   ```sql
   CREATE TABLE elements (
     id INTEGER NOT NULL,
     elementName TEXT NOT NULL,
     atomicNumber INTEGER NOT NULL,
     symbol TEXT NOT NULL
   );
   ```

3. Yeni oluşturduğunuz tabloya bazı veriler ekleyin.

   ```sql
   INSERT INTO elements (id, elementName, atomicNumber, symbol)
   VALUES
     (1, 'Hydrogen', 1, 'H'),
     (2, 'Helium', 2, 'He'),
     (3, 'Lithium', 3, 'Li'),
     (4, 'Beryllium', 4, 'Be'),
     (5, 'Boron', 5, 'B'),
     (6, 'Carbon', 6, 'C'),
     (7, 'Nitrogen', 7, 'N'),
     (8, 'Oxygen', 8, 'O'),
     (9, 'Fluorine', 9, 'F'),
     (10, 'Neon', 10, 'Ne');
   ```

4. Worker'ınızda Neon veritabanı kimlik bilgilerini yapılandırın:

   Neon veritabanı bağlantı dizinizi Worker'ınıza gizli anahtar olarak eklemeniz gerekir. Bağlantı dizinizi [Neon Console](https://console.neon.tech)'dan **Connection Details** altından alın, ardından Wrangler kullanarak gizli anahtar olarak ekleyin:

   ```sh
   # Veritabanı bağlantı dizinini gizli anahtar olarak ekle
   npx wrangler secret put DATABASE_URL
   # İstendiğinde, Neon veritabanı bağlantı dizinizi yapıştırın
   ```

5. Worker'ınızda, veritabanınıza bağlanmak ve veri manipülasyonuna başlamak için `@neondatabase/serverless` sürücüsünü yükleyin:

   <PackageManagers pkg="@neondatabase/serverless" />

6. Aşağıdaki örnek, Worker'da Neon veritabanınıza nasıl sorgu yapılacağını gösterir. Neon'a bağlanmak için gereken kimlik bilgileri Worker'ınıza gizli anahtarlar olarak eklenmiştir.

   ```js
   import { Client } from "@neondatabase/serverless";

   export default {
   	async fetch(request, env, ctx) {
   		const client = new Client(env.DATABASE_URL);
   		await client.connect();
   		const { rows } = await client.query("SELECT * FROM elements");

   		return new Response(JSON.stringify(rows));
   	},
   };
   ```

Neon hakkında daha fazla bilgi için [Neon'un resmi dokümantasyonuna](https://neon.tech/docs/introduction) bakın.
