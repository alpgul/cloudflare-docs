[PlanetScale](https://planetscale.com/), MySQL uyumlu ve PostgreSQL veritabanları sağlayan, onları daha ölçeklenebilir, yönetmesi daha kolay ve güvenli hale getiren bir veritabanı platformudur.

:::note

PlanetScale'a [Hyperdrive](/hyperdrive) (önerilen) kullanarak veya PlanetScale sunucusuz sürücüsü `@planetscale/database` kullanarak bağlanabilirsiniz. Her ikisi de bağlantı havuzlama sağlar ve Workers'dan veritabanınıza güvenli bir bağlantı oluşturmak için gereken gidiş-dönüş miktarını azaltır.

Hyperdrive, veritabanı bağlantı kurulumunu ve bağlantı havuzlamasını Cloudflare ağı boyunca gerçekleştirdiği için daha düşük gecikmeler sağlayabilir. Hyperdrive yerel veritabanı sürücülerini, kütüphanelerini ve ORM'leri destekler ve tüm [Workers planlarında](/hyperdrive/platform/pricing/) dahildir. [Hyperdrive'un Nasıl Çalıştığı](/hyperdrive/configuration/how-hyperdrive-works/) hakkında daha fazla bilgi edinin.

:::

## PlanetScale ile entegrasyon kurma

PlanetScale ile entegrasyon kurmak için:

1. Bağlanmak için mevcut bir PlanetScale veritabanına sahip olmanız gerekir. [PlanetScale veritabanı oluşturun](https://planetscale.com/docs/tutorials/planetscale-quick-start-guide#create-a-database) veya [mevcut veritabanını PlanetScale'a aktarın](https://planetscale.com/docs/imports/database-imports#overview).

2. [PlanetScale web konsolundan](https://planetscale.com/docs/concepts/web-console#get-started), aşağıdaki sorgu ile bir `products` tablosu oluşturun:

   ```sql
   CREATE TABLE products (
     id int NOT NULL AUTO_INCREMENT PRIMARY KEY,
     name varchar(255) NOT NULL,
     image_url varchar(255),
     category_id INT,
     KEY category_id_idx (category_id)
   );
   ```

3. Yeni oluşturduğunuz tabloya bazı veriler ekleyin. Tablonuza bir ürün ve kategori eklemek için aşağıdaki komutu çalıştırın:

   ```sql
   INSERT INTO products (name, image_url, category_id)
   VALUES ('Ballpoint pen', 'https://example.com/500x500', '1');
   ```

4. Worker'ınızda PlanetScale veritabanı kimlik bilgilerini yapılandırın:

   PlanetScale veritabanı kimlik bilgilerinizi Worker'ınıza gizli anahtarlar olarak eklemeniz gerekir. Bağlantı dizisi oluşturarak [PlanetScale Dashboard](https://app.planetscale.com)'dan bağlantı detaylarınızı alın, ardından bunları Wrangler kullanarak gizli anahtarlar olarak ekleyin:

   ```sh
   # Veritabanı host'unu gizli anahtar olarak ekle
   npx wrangler secret put DATABASE_HOST
   # İstendiğinde, PlanetScale host'unuzu yapıştırın

   # Veritabanı kullanıcı adını gizli anahtar olarak ekle
   npx wrangler secret put DATABASE_USERNAME
   # İstendiğinde, PlanetScale kullanıcı adınızı yapıştırın

   # Veritabanı şifresini gizli anahtar olarak ekle
   npx wrangler secret put DATABASE_PASSWORD
   # İstendiğinde, PlanetScale şifrenizi yapıştırın
   ```

5. Worker'ınızda, PlanetScale veritabanınıza bağlanmak ve veri manipülasyonuna başlamak için `@planetscale/database` sürücüsünü yükleyin:

   <PackageManagers pkg="@planetscale/database" />

6. Aşağıdaki örnek, Worker'da PlanetScale veritabanınıza nasıl sorgu yapılacağını gösterir. PlanetScale'a bağlanmak için gereken kimlik bilgileri Worker'ınıza gizli anahtarlar olarak eklenmiştir.

   ```js
   import { connect } from "@planetscale/database";

   export default {
   	async fetch(request, env) {
   		const config = {
   			host: env.DATABASE_HOST,
   			username: env.DATABASE_USERNAME,
   			password: env.DATABASE_PASSWORD,
   			// see https://github.com/cloudflare/workerd/issues/698
   			fetch: (url, init) => {
   				delete init["cache"];
   				return fetch(url, init);
   			},
   		};

   		const conn = connect(config);
   		const data = await conn.execute("SELECT * FROM products;");
   		return new Response(JSON.stringify(data.rows), {
   			status: 200,
   			headers: {
   				"Content-Type": "application/json",
   			},
   		});
   	},
   };
   ```

PlanetScale hakkında daha fazla bilgi için [PlanetScale'un resmi dokümantasyonuna](https://docs.planetscale.com/) bakın.
