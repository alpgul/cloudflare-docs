[Upstash](https://upstash.com/), Redis\* ve Kafka API'si ile sunucusuz veritabanıdır. Upstash ayrıca sunucusuz için tasarlanmış görev kuyruğu/zamanlayıcı olan QStash'i de sunar.

## Redis için Upstash

Upstash ile entegrasyon kurmak için:

1. Bağlanmak için mevcut bir Upstash veritabanına sahip olmanız gerekir. [Upstash veritabanı oluşturun](https://docs.upstash.com/redis#create-a-database) veya [mevcut veritabanından Upstash'e veri yükleyin](https://docs.upstash.com/redis/howto/connectclient).

2. Upstash veritabanınıza bazı veriler ekleyin. Upstash veritabanınıza veri eklemenin iki yolu vardır:

   - Upstash konsolunuzdan doğrudan CLI'yi kullanın.
   - Alternatif olarak, [redis-cli](https://redis.io/docs/getting-started/installation/)'yi yerel olarak yükleyin ve aşağıdaki komutları çalıştırın.

   ```sh
   set GB "Ey up?"
   ```

   ```sh output
   OK
   ```

   ```sh
   set US "Yo, what's up?"
   ```

   ```sh output
   OK
   ```

   ```sh
   set NL "Hoi, hoe gaat het?"
   ```

   ```sh output
   OK
   ```

3. Worker'ınızda Upstash Redis kimlik bilgilerini yapılandırın:

   Upstash Redis veritabanı URL'nizi ve token'ınızı Worker'ınıza gizli anahtarlar olarak eklemeniz gerekir. Bunları [Upstash Console](https://console.upstash.com)'dan veritabanı detaylarınız altından alın, ardından bunları Wrangler kullanarak gizli anahtarlar olarak ekleyin:

   ```sh
   # Upstash Redis URL'sini gizli anahtar olarak ekle
   npx wrangler secret put UPSTASH_REDIS_REST_URL
   # İstendiğinde, Upstash Redis REST URL'nizi yapıştırın
   
   # Upstash Redis token'ını gizli anahtar olarak ekle
   npx wrangler secret put UPSTASH_REDIS_REST_TOKEN
   # İstendiğinde, Upstash Redis REST token'ınızı yapıştırın
   ```

4. Worker'ınızda, veritabanınıza bağlanmak ve veri manipülasyonuna başlamak için `@upstash/redis`, HTTP istemcisini yükleyin:

   <PackageManagers pkg="@upstash/redis" />

5. Aşağıdaki örnek, Worker'da Upstash veritabanınıza nasıl sorgu yapılacağını gösterir. Upstash'e bağlanmak için gereken kimlik bilgileri Worker'ınıza gizli anahtarlar olarak eklenmiştir.

   ```js
   import { Redis } from "@upstash/redis/cloudflare";

   export default {
   	async fetch(request, env) {
   		const redis = Redis.fromEnv(env);

   		const country = request.headers.get("cf-ipcountry");
   		if (country) {
   			const greeting = await redis.get(country);
   			if (greeting) {
   				return new Response(greeting);
   			}
   		}

   		return new Response("Hello What's up!");
   	},
   };
   ```

   :::note

   `Redis.fromEnv(env)` entegrasyonda oluşturulan varsayılan `url` ve `token` adlarını otomatik olarak alır.

   Gizli anahtarları yeniden adlandırdıysanız, bunları [Upstash temel örneğinde](https://docs.upstash.com/redis/sdks/redis-ts/getstarted#basic-usage) olduğu gibi açıkça bildirmeniz gerekir.

   :::

Upstash hakkında daha fazla bilgi için [Upstash dokümantasyonuna](https://docs.upstash.com/redis) bakın.

## Upstash Kafka

Upstash Kafka ile entegrasyon kurmak için:

1. [Kafka cluster ve topic](https://docs.upstash.com/kafka) oluşturun.

2. Worker'ınızda Upstash Kafka kimlik bilgilerini yapılandırın:

   Upstash Kafka bağlantı detaylarınızı Worker'ınıza gizli anahtarlar olarak eklemeniz gerekir. Bunları [Upstash Console](https://console.upstash.com)'dan Kafka cluster detaylarınız altından alın, ardından bunları Wrangler kullanarak gizli anahtarlar olarak ekleyin:

   ```sh
   # Upstash Kafka URL'sini gizli anahtar olarak ekle
   npx wrangler secret put UPSTASH_KAFKA_REST_URL
   # İstendiğinde, Upstash Kafka REST URL'nizi yapıştırın
   
   # Upstash Kafka kullanıcı adını gizli anahtar olarak ekle
   npx wrangler secret put UPSTASH_KAFKA_REST_USERNAME
   # İstendiğinde, Upstash Kafka kullanıcı adınızı yapıştırın
   
   # Upstash Kafka şifresini gizli anahtar olarak ekle
   npx wrangler secret put UPSTASH_KAFKA_REST_PASSWORD
   # İstendiğinde, Upstash Kafka şifrenizi yapıştırın
   ```

3. Worker'ınızda HTTP/REST tabanlı Kafka istemcisi `@upstash/kafka`'yı yükleyin:

   <PackageManagers pkg="@upstash/kafka" />

4. Kafka'ya veri göndermek için [upstash-kafka](https://github.com/upstash/upstash-kafka/blob/main/README.md) JavaScript SDK'sını kullanın.

Daha fazla bilgi için [Workers ile Kafka kurulumu hakkında Upstash dokümantasyonuna](https://docs.upstash.com/kafka/real-time-analytics/realtime_analytics_serverless_kafka_setup#option-1-cloudflare-workers) bakın. `url`, `username` ve `password`'u entegrasyon tarafından ayarlanan değişkenlerle değiştirin.

## Upstash QStash

Upstash QStash ile entegrasyon kurmak için:

1. Mesajlarınızı göndermek istediğiniz [genel olarak erişilebilir HTTP endpoint](https://docs.upstash.com/qstash#1-public-api)'i yapılandırın.

2. Worker'ınızda Upstash QStash kimlik bilgilerini yapılandırın:

   Upstash QStash token'ınızı Worker'ınıza gizli anahtar olarak eklemeniz gerekir. Token'ınızı [Upstash Console](https://console.upstash.com)'dan QStash ayarları altından alın, ardından bunu Wrangler kullanarak gizli anahtar olarak ekleyin:

   ```sh
   # QStash token'ını gizli anahtar olarak ekle
   npx wrangler secret put QSTASH_TOKEN
   # İstendiğinde, QStash token'ınızı yapıştırın
   ```

3. Worker'ınızda veritabanı QStash endpoint'inize bağlanmak için HTTP istemcisi `@upstash/qstash`'i yükleyin:

   <PackageManagers pkg="@upstash/qstash" />

4. [Cloudflare Worker'ınızda QStash'ten webhook'ları nasıl alacağınız](https://docs.upstash.com/qstash/quickstarts/cloudflare-workers#3-use-qstash-in-your-handler) hakkında Upstash dokümantasyonuna bakın.
