[Supabase](https://supabase.com/), açık kaynaklı Firebase alternatifi ve gerçek zamanlı işlevsellik, veritabanı yedeklemeleri ve uzantılar sunan PostgreSQL veritabanı hizmetidir. Supabase ile geliştiriciler hızla PostgreSQL veritabanı kurabilir ve uygulamalar oluşturabilir.

:::note

Supabase istemcisi (`@supabase/supabase-js`), veritabanı erişimi dahil olmak üzere Supabase'in çeşitli özelliklerine erişim sağlar. Supabase istemci işlevselliğinin tamamına erişime ihtiyacınız varsa, Supabase istemcisini kullanın.

Supabase Postgres veritabanına doğrudan bağlanmak istiyorsanız, [Hyperdrive](/hyperdrive) kullanarak bağlanın. Hyperdrive, veritabanı bağlantı kurulumunu ve bağlantı havuzlamasını Cloudflare ağı boyunca gerçekleştirdiği için daha düşük gecikmeler sağlayabilir. Hyperdrive yerel veritabanı sürücülerini, kütüphanelerini ve ORM'leri destekler ve tüm [Workers planlarında](/hyperdrive/platform/pricing/) dahildir. [Hyperdrive'un Nasıl Çalıştığı](/hyperdrive/configuration/how-hyperdrive-works/) hakkında daha fazla bilgi edinin.

:::

### Supabase istemci kurulumu

Supabase ile entegrasyon kurmak için:

1. Bağlanmak için mevcut bir Supabase veritabanına sahip olmanız gerekir. [Supabase veritabanı oluşturun](https://supabase.com/docs/guides/database/tables#creating-tables) veya [bağlanmak için mevcut bir veritabanınız olsun ve Supabase'den veri yükleyin](https://supabase.com/docs/guides/database/tables#loading-data).

2. Aşağıdaki sorgu ile bir `countries` tablosu oluşturun. Supabase dashboard'unuzda tablo oluşturmanın iki yolu vardır:

   - Tablo editörünü kullanın, bu da Postgres'i elektronik tablo gibi kurmanıza olanak tanır.
   - Alternatif olarak, [SQL editörünü](https://supabase.com/docs/guides/database/overview#the-sql-editor) kullanın:

   ```sql
   CREATE TABLE countries (
   id SERIAL PRIMARY KEY,
   name VARCHAR(255) NOT NULL
   );
   ```

3. Yeni oluşturduğunuz tabloya bazı veriler ekleyin. Tablonuza ülkeler eklemek için aşağıdaki komutları çalıştırın:

   ```sql
   INSERT INTO countries (name) VALUES ('United States');
   INSERT INTO countries (name) VALUES ('Canada');
   INSERT INTO countries (name) VALUES ('The Netherlands');
   ```

4. Worker'ınızda Supabase veritabanı kimlik bilgilerini yapılandırın:

   Supabase URL'nizi ve anon anahtarınızı Worker'ınıza gizli anahtarlar olarak eklemeniz gerekir. Bunları [Supabase Dashboard](https://supabase.com/dashboard)'dan **Settings** > **API** altından alın, ardından bunları Wrangler kullanarak gizli anahtarlar olarak ekleyin:

   ```sh
   # Supabase URL'sini gizli anahtar olarak ekle
   npx wrangler secret put SUPABASE_URL
   # İstendiğinde, Supabase proje URL'nizi yapıştırın

   # Supabase anon anahtarını gizli anahtar olarak ekle
   npx wrangler secret put SUPABASE_KEY
   # İstendiğinde, Supabase anon/genel anahtarınızı yapıştırın
   ```

5. Worker'ınızda, veritabanınıza bağlanmak ve veri manipülasyonuna başlamak için `@supabase/supabase-js` sürücüsünü yükleyin:

   <PackageManagers pkg="@supabase/supabase-js" />

6. Aşağıdaki örnek, Worker'da Supabase veritabanınıza nasıl sorgu yapılacağını gösterir. Supabase'e bağlanmak için gereken kimlik bilgileri Worker'ınıza gizli anahtarlar olarak eklenmiştir.

   ```js
   import { createClient } from "@supabase/supabase-js";

   export default {
   	async fetch(request, env) {
   		const supabase = createClient(env.SUPABASE_URL, env.SUPABASE_KEY);
   		const { data, error } = await supabase.from("countries").select("*");
   		if (error) throw error;
   		return new Response(JSON.stringify(data), {
   			headers: {
   				"Content-Type": "application/json",
   			},
   		});
   	},
   };
   ```

Supabase hakkında daha fazla bilgi için [Supabase'in resmi dokümantasyonuna](https://supabase.com/docs) bakın.
