[Turso](https://turso.tech/), SQLite'in açık kaynaklı bir fork'u olan [libSQL](https://libsql.org/) tabanlı kenar barındırılan, dağıtılmış veritabanıdır. Turso, sorguların dünyanın herhangi bir yerinden geldiği uygulamalar için sorgu gecikmesini minimize etmek üzere tasarlanmıştır.

## Turso ile entegrasyon kurma

Turso ile entegrasyon kurmak için:

1. Veritabanı oluşturmak ve doldurmak için Turso CLI'yi yüklemeniz gerekir. Terminalinizde Turso CLI'yi yüklemek için aşağıdaki iki komuttan birini kullanın:

   ```sh
   # macOS ve linux'ta homebrew ile
   brew install tursodatabase/tap/turso

   # Manuel scriptli kurulum
   curl -sSfL https://get.tur.so/install.sh | bash
   ```

   Ardından, Turso CLI'nin yüklendiğinden emin olmak için aşağıdaki komutu çalıştırın:

   ```sh
   turso --version
   ```

2. İlk Turso veritabanınızı oluşturmadan önce, GitHub hesabınızla kimlik doğrulaması yapmanız gerekir:

   ```sh
   turso auth login
   ```

   ```sh output
   Waiting for authentication...
   ✔  Success! Logged in as <YOUR_GITHUB_USERNAME>
   ```

   Kimlik doğrulaması yaptıktan sonra, `turso db create <DATABASE_NAME>` komutunu kullanarak bir veritabanı oluşturabilirsiniz. Turso bir veritabanı oluşturacak ve size en yakın konumu otomatik olarak seçecektir.

   ```sh
   turso db create my-db
   ```

   ```sh output

   # Örnek:
   Creating database my-db in Amsterdam, Netherlands (ams)

   # Başarılı olduktan sonra:
   Created database my-db in Amsterdam, Netherlands (ams) in 13 seconds.
   ```

   İlk veritabanı oluşturulduktan sonra, artık ona doğrudan bağlanabilir ve ona karşı SQL sorguları çalıştırabilirsiniz.

   ```sh
   turso db shell my-db
   ```

3. Az önce açtığınız shell'e aşağıdaki SQL sorgusunu kopyalayın:

   ```sql
   CREATE TABLE elements (
     id INTEGER NOT NULL,
     elementName TEXT NOT NULL,
     atomicNumber INTEGER NOT NULL,
     symbol TEXT NOT NULL
   );

   INSERT INTO elements (id, elementName, atomicNumber, symbol)
   VALUES (1, 'Hydrogen', 1, 'H'),
     (2, 'Helium', 2, 'He'),
     (3, 'Lithium', 3, 'Li'),
     (4, 'Beryllium', 4, 'Be'),
     (5, 'Boron', 5, 'B'),
     (6, 'Carbon', 6, 'C'),
     (7, 'Nitrogen', 7, 'N'),
     (8, 'Oxygen', 8, 'O'),
     (9, 'Fluorine', 9, 'F'),
     (10, 'Neon', 10, 'Ne');
   ```

4. Worker'ınızda Turso veritabanı kimlik bilgilerini yapılandırın:

   Turso veritabanı URL'nizi ve kimlik doğrulama token'ınızı Worker'ınıza gizli anahtarlar olarak eklemeniz gerekir. Önce veritabanı URL'nizi alın ve bir kimlik doğrulama token'ı oluşturun:

   ```sh
   # Veritabanı URL'nizi alın
   turso db show my-db --url
   
   # Kimlik doğrulama token'ı oluşturun
   turso db tokens create my-db
   ```

   Ardından bunları Wrangler kullanarak Worker'ınıza gizli anahtarlar olarak ekleyin:

   ```sh
   # Veritabanı URL'sini gizli anahtar olarak ekle
   npx wrangler secret put TURSO_URL
   # İstendiğinde, veritabanı URL'nizi yapıştırın
   
   # Kimlik doğrulama token'ını gizli anahtar olarak ekle  
   npx wrangler secret put TURSO_AUTH_TOKEN
   # İstendiğinde, kimlik doğrulama token'ınızı yapıştırın
   ```

5. Worker'ınızda Turso istemci kütüphanesini yükleyin:

   <PackageManagers pkg="@libsql/client" />

6. Aşağıdaki örnek, Worker'da Turso veritabanınıza nasıl sorgu yapılacağını gösterir. Turso'ya bağlanmak için gereken kimlik bilgileri Worker'ınıza [gizli anahtarlar](/workers/configuration/secrets/) olarak eklenmiştir.

   ```ts
   import { Client as LibsqlClient, createClient } from "@libsql/client/web";

   export interface Env {
   	TURSO_URL?: string;
   	TURSO_AUTH_TOKEN?: string;
   }

   export default {
   	async fetch(request, env, ctx): Promise<Response> {
   		const client = buildLibsqlClient(env);

   		try {
   			const res = await client.execute("SELECT * FROM elements");
   			return new Response(JSON.stringify(res), {
   				status: 200,
   				headers: { "Content-Type": "application/json" },
   			});
   		} catch (error) {
   			console.error("Error executing SQL query:", error);
   			return new Response(
   				JSON.stringify({ error: "Internal Server Error" }),
   				{
   					status: 500,
   				},
   			);
   		}
   	},
   } satisfies ExportedHandler<Env>;

   function buildLibsqlClient(env: Env): LibsqlClient {
   	const url = env.TURSO_URL?.trim();
   	if (url === undefined) {
   		throw new Error("TURSO_URL env var is not defined");
   	}

   	const authToken = env.TURSO_AUTH_TOKEN?.trim();
   	if (authToken == undefined) {
   		throw new Error("TURSO_AUTH_TOKEN env var is not defined");
   	}

   	return createClient({ url, authToken });
   }
   ```

   - libSQL istemci kütüphanesi import'u `@libsql/client/web`, Cloudflare Workers ile çalışırken tam olarak gösterildiği gibi import edilmelidir. Web olmayan import Workers ortamında çalışmayacaktır.
   - `Env` interface'i, 4. adımda Turso entegrasyonunu eklediğinizde tanımladığınız [ortam değişkeni](/workers/configuration/environment-variables/) ve [gizli anahtar](/workers/configuration/secrets/) içerir.
   - `Env` interface'i ayrıca libSQL istemci nesnesini ve router'ı önbelleğe alır, bu da Worker'a yapılan ilk istekte oluşturulmuştur.
   - Worker, `elements` veritabanını sorgulamak için `buildLibsqlClient` kullanır ve yanıtı JSON nesnesi olarak döndürür.

Ortamınız yapılandırıldıktan ve kodunuz hazır olduktan sonra, dağıtmadan önce Worker'ınızı yerel olarak test edebilirsiniz.

Turso hakkında daha fazla bilgi için [Turso'nun resmi dokümantasyonuna](https://docs.turso.tech) bakın.
