# Wrangler vs Vite ne zaman kullanılır

Wrangler ve Cloudflare Vite plugin'i arasında karar vermek, projenizin odak noktasına ve geliştirme iş akışına bağlıdır. Seçim yapmanıza yardımcı olacak bazı hızlı yönergeler:

## Wrangler ne zaman kullanılır

- **Backend ve Worker odaklı:**
  Öncelikle API'ler, sunucusuz fonksiyonlar veya arka plan görevleri oluşturuyorsanız, Wrangler'ı kullanın.

- **Uzak geliştirme:**
  Projenizin Worker'ınızı Cloudflare'in ağında uzaktan çalıştırma yeteneğine ihtiyacı varsa, Wrangler'ın `--remote` bayrağını kullanın.

- **Basit frontend'ler:**
  Minimal frontend gereksinimleriniz varsa ve hot reloading veya gelişmiş bundling'e ihtiyacınız yoksa, Wrangler yeterli olabilir.

## Cloudflare Vite Plugin ne zaman kullanılır

[Vite plugin'ini](/workers/vite-plugin/) şu durumlarda kullanın:

- **Frontend odaklı geliştirme:**
  Zaten React, Vue, Svelte veya Solid gibi modern frontend framework'leri ile Vite kullanıyorsanız, Vite plugin'i geliştirme iş akışınıza entegre olur.

- **React Router v7:**
  [React Router v7](https://reactrouter.com/) (Remix'in halefi) kullanıyorsanız, Vite plugin'i tarafından tam yığın SSR framework'ü olarak resmi olarak desteklenir.

- **Hızlı yineleme (HMR):**
  Tarayıcıda neredeyse anında güncellemelere ihtiyacınız varsa, Vite plugin'i yerel geliştirme sırasında [Hot Module Replacement (HMR)](https://vite.dev/guide/features.html#hot-module-replacement) sağlar.

- **Gelişmiş optimizasyonlar:**
  Daha gelişmiş optimizasyonlara (kod bölme, verimli bundling, CSS işleme, build zamanı dönüşümleri, vb.) ihtiyacınız varsa, Vite güçlü bir seçimdir.

- **Daha fazla esneklik:**
  Vite'ın gelişmiş yapılandırma seçenekleri ve büyük plugin ekosistemi nedeniyle, geliştirme deneyiminizi ve build çıktınızı özelleştirmek için daha fazla esneklik vardır.
