Cloudflare Workers'dan üçüncü taraf API'lerle entegre olmak için, API endpoint'ine HTTP istekleri yapmak için [fetch API](/workers/runtime-apis/fetch/)'yi kullanın. Ardından yanıt verilerini içeriğinizi gerektiği gibi değiştirmek veya manipüle etmek için kullanın.

Örneğin, bir hava durumu API'si ile entegre olmak istiyorsanız, API endpoint'ine bir fetch isteği yapın ve mevcut hava durumu verilerini alın. Ardından bu verileri web sitenizde mevcut hava durumu koşullarını göstermek için kullanın.

`fetch()` isteğini yapmak için, projenizin `src/index.js` dosyasına aşağıdaki kodu ekleyin:

```js
async function handleRequest(request) {
	// Üçüncü taraf API endpoint'ine fetch isteği yapın
	const response = await fetch("https://weather-api.com/endpoint", {
		method: "GET",
		headers: {
			"Content-Type": "application/json",
		},
	});

	// Yanıttan veriyi alın
	const data = await response.json();

	// Veriyi içeriğinizi gerektiği gibi değiştirmek veya manipüle etmek için kullanın
	return new Response(data);
}
```

## Kimlik Doğrulama

API'niz kimlik doğrulama gerektiriyorsa, kimlik bilgilerinizi güvenli bir şekilde saklamak için Wrangler gizli anahtarlarını kullanın. Bunu yapmak için, aşağıdaki [`wrangler secret`](/workers/wrangler/commands/#secret) komutunu kullanarak Cloudflare Workers projenizde bir gizli anahtar oluşturun:

```sh
wrangler secret put SECRET_NAME
```

Ardından, aşağıdaki kod parçacığını kullanarak kodunuzda gizli anahtar değerini alın:

```js
const secretValue = env.SECRET_NAME;
```

Ardından harici hizmetle kimlik doğrulama yapmak için gizli anahtar değerini kullanın. Örneğin, harici hizmet kimlik doğrulama için bir API anahtarı gerektiriyorsa, bunu istek başlıklarınızda dahil edin.

mTLS kimlik doğrulaması gerektiren hizmetler için, bir istemci sertifikası sunmak üzere [mTLS sertifikalarını](/workers/runtime-apis/bindings/mtls) kullanın.

## İpuçları

- Üçüncü taraf API'den gelen verileri önbelleğe almak için [Cache API](/workers/runtime-apis/cache/)'yi kullanın. Bu, API'ye yapılan önbelleğe alınabilir istekleri optimize etmenizi sağlar. Cloudflare Workers'dan üçüncü taraf API'lerle entegre olmak uygulamanıza ek işlevsellik ve özellikler ekler.

- Harici API'lerle iletişim kurarken [Özel Alanlar](/workers/configuration/routing/custom-domains/) kullanın, bu Worker'ınızı temel uygulamanız olarak ele alır.
