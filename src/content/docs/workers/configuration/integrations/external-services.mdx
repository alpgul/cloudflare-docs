Birçok harici hizmet, API'leriyle etkileşim kurmak için kütüphaneler ve SDK'lar sağlar. Node uyumlu kütüphanelerin çoğu Worker'larda kutudan çıktığı gibi çalışırken, `fs`, `http/net` uygulayan veya tarayıcı `window`'una erişen bazıları, v8 tabanlı olan Workers runtime'ına doğrudan çevrilmez.

## Kimlik Doğrulama

Hizmetiniz kimlik doğrulama gerektiriyorsa, kimlik bilgilerinizi güvenli bir şekilde saklamak için Wrangler gizli anahtarlarını kullanın. Bunu yapmak için, aşağıdaki [`wrangler secret`](/workers/wrangler/commands/#secret) komutunu kullanarak Cloudflare Workers projenizde bir gizli anahtar oluşturun:

```sh
wrangler secret put SECRET_NAME
```

Ardından, aşağıdaki kod parçacığını kullanarak kodunuzda gizli anahtar değerini alın:

```js
const secretValue = env.SECRET_NAME;
```

Ardından harici hizmetle kimlik doğrulama yapmak için gizli anahtar değerini kullanın. Örneğin, harici hizmet kimlik doğrulama için bir API anahtarı gerektiriyorsa, gizli anahtarı kütüphanenizin yapılandırmasına dahil edin.

mTLS kimlik doğrulaması gerektiren hizmetler için, bir istemci sertifikası sunmak üzere [mTLS sertifikalarını](/workers/runtime-apis/bindings/mtls) kullanın.

Harici API'lerle iletişim kurarken [Özel Alanlar](/workers/configuration/routing/custom-domains/) kullanın, bu Worker'ınızı temel uygulamanız olarak ele alır.
