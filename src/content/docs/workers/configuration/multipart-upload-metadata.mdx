import { Type, MetaInfo } from "~/components";

:::note

Workers yüklemek için yeni bir API vardır. Daha fazla bilgi için [bu dokümantasyona](/workers/platform/infrastructure-as-code#cloudflare-rest-api) bakın.
:::

[Workers Script Upload API](/api/resources/workers/subresources/scripts/methods/update/) veya [Version Upload API](/api/resources/workers/subresources/scripts/subresources/versions/methods/create/)'yi doğrudan kullanıyorsanız, `multipart/form-data` yüklemeleri için bir `metadata` bölümü belirtmeniz gerekir. Bu meta veri, Worker'ın yapılandırmasını JSON formatında tanımlar, [wrangler.toml dosyası](/workers/wrangler/configuration/) ile benzerdir.

## Örnek `metadata`

```json
{
	"main_module": "main.js",
	"bindings": [
		{
			"type": "plain_text",
			"name": "MESSAGE",
			"text": "Merhaba dünya!"
		}
	],
	"compatibility_date": "2021-09-14"
}
```

:::note

Workers Script Upload API ile kullanılan meta veri örneklerini [burada](/workers/platform/infrastructure-as-code#cloudflare-rest-api) görün.
:::

## Öznitelikler

Aşağıdaki öznitelikler üst düzeyde yapılandırılabilir.

:::note

En azından, bir Worker yüklemek için `main_module` anahtarı gereklidir.
:::

- `main_module` <Type text="string" /> <MetaInfo text="required" />

  - Worker'ın çalıştırılacak modül giriş noktasını içeren bölüm adı. Örneğin, `main.js`.

- `assets` <Type text="object" /> <MetaInfo text="optional" />

  - Worker için [Asset](/workers/static-assets/) yapılandırması.
  - `config` <Type text="object" /> <MetaInfo text="optional" />
    - [html_handling](/workers/static-assets/routing/advanced/html-handling/) HTML içeriği için isteklerin yönlendirmelerini ve yeniden yazmalarını belirler.
    - [not_found_handling](/workers/static-assets/#routing-behavior) bir isteğin statik bir varlıkla eşleşmediğinde yanıtı belirler.
  - `jwt` alanı, varlıkların bir Worker'a eklenmesini yetkilendiren bir token sağlar.

- `keep_assets` <Type text="boolean" /> <MetaInfo text="optional" />

  - Varlıkların önceden yüklenmiş bir Worker sürümünden korunup korunmayacağını belirtir; tamamlama tokeni sağlamak yerine kullanılır.

- `bindings` array\[object] optional

  - Worker'da açığa çıkarılacak [Bağlamalar](#bindings).

- `placement` <Type text="object" /> <MetaInfo text="optional" />

  - Worker için [Akıllı yerleştirme](/workers/configuration/smart-placement/) nesnesi.
  - `mode` alanı yalnızca otomatik yerleştirme için `smart`'ı destekler.

- `compatibility_date` <Type text="string" /> <MetaInfo text="optional" />

  - Workers runtime'da hedeflenen desteği gösteren [Uyumluluk Tarihi](/workers/configuration/compatibility-dates/#setting-compatibility-date). Bu tarihten sonra runtime'daki geriye dönük uyumsuz düzeltmeler bu Worker'ı etkilemeyecektir. `compatibility_date` ayarlamak şiddetle önerilir, aksi takdirde API aracılığıyla yükleme sırasında bayrakların etkili olmadan önceki en eski uyumluluk tarihine (2021-11-02) varsayılan olarak ayarlanır.

- `compatibility_flags` array\[string] optional

  - Workers runtime'da belirli özellikleri etkinleştiren veya devre dışı bırakan [Uyumluluk Bayrakları](/workers/configuration/compatibility-flags/#setting-compatibility-flags). Yaklaşan özellikleri etkinleştirmek veya `compatibility_date`'e dahil edilmeyen belirli değişikliklere katılmak veya çıkmak için kullanılır.

## Ek öznitelikler: [Workers Script Upload API](/api/resources/workers/subresources/scripts/methods/update/)

[Anında dağıtılan yüklemeler](/workers/configuration/versions-and-deployments/#upload-a-new-version-and-deploy-it-immediately) için, aşağıdaki **ek** öznitelikler üst düzeyde yapılandırılabilir.

:::note

Bu öznitelikler sürüm yüklemeleri için **mevcut değildir**.
:::

- `migrations` array\[object] optional

  - Uygulanacak [Durable Objects migrations](/durable-objects/reference/durable-objects-migrations/).

- `logpush` <Type text="boolean" /> <MetaInfo text="optional" />

  - Worker için [Logpush](/cloudflare-for-platforms/cloudflare-for-saas/hostname-analytics/#logpush)'in açık olup olmadığı.

- `tail_consumers` array\[object] optional

  - Ekli Worker'dan logları tüketecek [Tail Workers](/workers/observability/logs/tail-workers/).

- `tags` array\[string] optional

  - Bu Worker için etiket olarak kullanılacak dize listesi.

## Ek öznitelikler: [Version Upload API](/api/resources/workers/subresources/scripts/subresources/versions/methods/create/)

[Sürüm yüklemeleri](/workers/configuration/versions-and-deployments/#upload-a-new-version-to-be-gradually-deployed-or-deployed-at-a-later-time) için, aşağıdaki **ek** öznitelikler üst düzeyde yapılandırılabilir.

:::note

Bu öznitelikler anında dağıtılan yüklemeler için **mevcut değildir**.
:::

- `annotations` <Type text="object" /> <MetaInfo text="optional" />

  - Worker sürümüne özel açıklamalar nesnesi.
  - `workers/message` sürüm için özel bir mesaj belirtir.
  - `workers/tag` sürüm için özel bir tanımlayıcı belirtir.
  - `workers/alias` bu sürüm için özel bir takma ad belirtir.

## Bağlamalar

Worker'lar [bağlamalar](/workers/runtime-apis/bindings/) kullanarak Cloudflare Developer Platform'daki kaynaklarla etkileşim kurabilir. `metadata` bölümünde bağlamaların nasıl ekleneceğini gösteren JSON örneğine bakın.

```json

	"bindings": [
		{
			"type": "ai",
			"name": "<VARIABLE_NAME>"
		},
		{
			"type": "analytics_engine",
			"name": "<VARIABLE_NAME>",
			"dataset": "<DATASET>"
		},
		{
			"type": "assets",
			"name": "<VARIABLE_NAME>"
		},
		{
			"type": "browser_rendering",
			"name": "<VARIABLE_NAME>"
		},
		{
			"type": "d1",
			"name": "<VARIABLE_NAME>",
			"id": "<D1_ID>"
		},
		{
			"type": "durable_object_namespace",
			"name": "<VARIABLE_NAME>",
			"class_name": "<DO_CLASS_NAME>"
		},
		{
			"type": "hyperdrive",
			"name": "<VARIABLE_NAME>",
			"id": "<HYPERDRIVE_ID>"
		},
		{
			"type": "kv_namespace",
			"name": "<VARIABLE_NAME>",
			"namespace_id": "<KV_ID>"
		},
		{
			"type": "mtls_certificate",
			"name": "<VARIABLE_NAME>",
			"certificate_id": "<MTLS_CERTIFICATE_ID>"
		},
		{
			"type": "plain_text",
			"name": "<VARIABLE_NAME>",
			"text": "<VARIABLE_VALUE>"
		},
		{
			"type": "queue",
			"name": "<VARIABLE_NAME>",
			"queue_name": "<QUEUE_NAME>"
		},
		{
			"type": "r2_bucket",
			"name": "<VARIABLE_NAME>",
			"bucket_name": "<R2_BUCKET_NAME>"
		},
		{
			"type": "secret_text",
			"name": "<VARIABLE_NAME>",
			"text": "<SECRET_VALUE>"
		},
		{
			"type": "service",

		{

			"service": "<WORKER_NAME>"
		},
		{
			"type": "vectorize",

		},
		{
			"type": "version_metadata",
			"name": "<VARIABLE_NAME>"
		}
	]
}
```
