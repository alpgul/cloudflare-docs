Workers Sites [Wrangler](https://github.com/cloudflare/workers-sdk/tree/main/packages/wrangler) gerektirir — [en son sürümü](/workers/wrangler/install-and-update/#update-wrangler) kullandığınızdan emin olun.

Önceden var olan Worker projeniz varsa, Worker'a statik varlıkları sunmak için Workers Sites kullanabilirsiniz.

## Başlangıç

1. Projenizin kökünde varlıkları içerecek bir dizin oluşturun (örneğin, `./public`)

2. Wrangler dosyanıza bunu işaret etmek için yapılandırma ekleyin.

   <WranglerConfig>

   ```toml
   [site]
   bucket = "./public" # Statik varlıklarınızla dizini ekleyin!
   ```

   </WranglerConfig>

3. Projenizde `@cloudflare/kv-asset-handler` paketini yükleyin:

   ```sh
   npm i -D @cloudflare/kv-asset-handler
   ```

4. `getAssetFromKV()` fonksiyonunu Worker giriş noktanıza içe aktarın ve statik varlıklarla yanıt vermek için kullanın.

<Tabs> <TabItem label="Module Worker" icon="seti:javascript">

```js
import { getAssetFromKV } from "@cloudflare/kv-asset-handler";
import manifestJSON from "__STATIC_CONTENT_MANIFEST";
const assetManifest = JSON.parse(manifestJSON);

export default {
	async fetch(request, env, ctx) {
		try {
			// Bir varlık sunmak mı yoksa orijinal Worker kodunuzu çalıştırmak mı gerektiğine karar vermek için mantık ekleyin
			return await getAssetFromKV(
				{
					request,
					waitUntil: ctx.waitUntil.bind(ctx),
				},
				{
					ASSET_NAMESPACE: env.__STATIC_CONTENT,
					ASSET_MANIFEST: assetManifest,
				},
			);
		} catch (e) {
			let pathname = new URL(request.url).pathname;
			return new Response(`"${pathname}" not found`, {
				status: 404,
				statusText: "not found",
			});
		}
	},
};
```

</TabItem> <TabItem label="Service Worker" icon="seti:javascript">

```js
import { getAssetFromKV } from "@cloudflare/kv-asset-handler";

addEventListener("fetch", (event) => {
	event.respondWith(handleEvent(event));
});

async function handleEvent(event) {
	try {
		// Bir varlık sunmak mı yoksa orijinal Worker kodunuzu çalıştırmak mı gerektiğine karar vermek için mantık ekleyin
		return await getAssetFromKV(event);
	} catch (e) {
		let pathname = new URL(event.request.url).pathname;
		return new Response(`"${pathname}" not found`, {
			status: 404,
			statusText: "not found",
		});
	}
}
```

</TabItem> </Tabs>

`getAssetFromKV()`'nin yapılandırılabilir seçenekleri hakkında daha fazla bilgi için [kv-asset-handler dokümantasyonuna](https://github.com/cloudflare/workers-sdk/tree/main/packages/kv-asset-handler) bakın.

5. Worker projenizle normalde yaptığınız gibi `wrangler deploy` veya `npx wrangler deploy` çalıştırın.
   Wrangler yapılandırılmış dizinde bulunan varlıkları otomatik olarak yükleyecektir.

   ```sh
   npx wrangler deploy
   ```
