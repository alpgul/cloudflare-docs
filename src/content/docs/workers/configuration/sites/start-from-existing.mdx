Workers Sites [Wrangler](https://github.com/cloudflare/workers-sdk/tree/main/packages/wrangler) gerektirir — [en son sürümü](/workers/wrangler/install-and-update/#update-wrangler) kullandığınızdan emin olun.

Önceden var olan statik site projesini dağıtmak için, önceden oluşturulmuş bir site ile başlayın. Workers Sites tüm statik site oluşturucularıyla çalışır, örneğin:

- [Hugo](https://gohugo.io/getting-started/quick-start/)
- [Gatsby](https://www.gatsbyjs.org/docs/quick-start/), Node gerektirir
- [Jekyll](https://jekyllrb.com/docs/), Ruby gerektirir
- [Eleventy](https://www.11ty.io/#quick-start), Node gerektirir
- [WordPress](https://wordpress.org) ([Pages ile statik WordPress sitelerini dağıtma](/pages/how-to/deploy-a-wordpress-site/) öğreticisine bakın)

## Başlangıç

1. Projenizin dizininin kökünde temel bir Worker oluşturmak için `wrangler init` komutunu çalıştırın:

   ```sh
   wrangler init -y
   ```

   Bu komut aşağıdaki dosyaları ekler/günceller:
   - `wrangler.jsonc`: Proje yapılandırmasını içeren dosya.
   - `package.json`: Wrangler `devDependencies` eklenir.
   - `tsconfig.json`: Worker'ı TypeScript'te yazmayı desteklemek için zaten yoksa eklenir.
   - `src/index.ts`: TypeScript'te yazılmış temel Cloudflare Worker.

2. Sitenizin build/çıktı dizinini Wrangler dosyasına ekleyin:

   <WranglerConfig>

   ```toml
   [site]
   bucket = "./public" # <-- Build dizin adınızı buraya ekleyin.
   ```

   </WranglerConfig>

   En popüler statik site oluşturucuları için varsayılan dizinler aşağıda listelenmiştir:
   - Hugo: `public`
   - Gatsby: `public`
   - Jekyll: `_site`
   - Eleventy: `_site`

3. Projenizde `@cloudflare/kv-asset-handler` paketini yükleyin:

   ```sh
   npm i -D @cloudflare/kv-asset-handler
   ```

4. `src/index.ts` içeriğini aşağıdaki kod parçacığıyla değiştirin:

<Tabs> <TabItem label="Module Worker" icon="seti:javascript">

```js
import { getAssetFromKV } from "@cloudflare/kv-asset-handler";
import manifestJSON from "__STATIC_CONTENT_MANIFEST";
const assetManifest = JSON.parse(manifestJSON);

export default {
	async fetch(request, env, ctx) {
		try {
			// Bir varlık sunmak mı yoksa orijinal Worker kodunuzu çalıştırmak mı gerektiğine karar vermek için mantık ekleyin
			return await getAssetFromKV(
				{
					request,
					waitUntil: ctx.waitUntil.bind(ctx),
				},
				{
					ASSET_NAMESPACE: env.__STATIC_CONTENT,
					ASSET_MANIFEST: assetManifest,
				},
			);
		} catch (e) {
			let pathname = new URL(request.url).pathname;
			return new Response(`"${pathname}" not found`, {
				status: 404,
				statusText: "not found",
			});
		}
	},
};
```

</TabItem> <TabItem label="Service Worker" icon="seti:javascript">

:::caution[Service Worker'lar kullanımdan kaldırıldı]

Service Worker'lar kullanımdan kaldırıldı ancak hala destekleniyor. Bunun yerine [Module Worker'lar](/workers/reference/migrate-to-module-workers/) kullanmanızı öneririz. Yeni özellikler Service Worker'lar için desteklenmeyebilir.

:::

```js
import { getAssetFromKV } from "@cloudflare/kv-asset-handler";

addEventListener("fetch", (event) => {
	event.respondWith(handleEvent(event));
});

async function handleEvent(event) {
	try {
		// Bir varlık sunmak mı yoksa orijinal Worker kodunuzu çalıştırmak mı gerektiğine karar vermek için mantık ekleyin
		return await getAssetFromKV(event);
	} catch (e) {
		let pathname = new URL(event.request.url).pathname;
		return new Response(`"${pathname}" not found`, {
			status: 404,
			statusText: "not found",
		});
	}
}
```

</TabItem> </Tabs>

5. Sitenizi Cloudflare'de önizlemek veya dağıtmak için `wrangler dev` veya `npx wrangler deploy` çalıştırın.
   Wrangler yapılandırılmış dizinde bulunan varlıkları otomatik olarak yükleyecektir.

   ```sh
   npx wrangler deploy
   ```

6. Sitenizi sahip olduğunuz ve zaten Cloudflare zone olarak eklediğiniz [özel alana](/workers/configuration/routing/custom-domains/) dağıtın. Wrangler dosyasına `route` özelliği ekleyin.

   <WranglerConfig>

   ```toml
   route = "https://example.com/*"
   ```

   </WranglerConfig>

   :::note

   `route`'u doğru şekilde yapılandırmak için [Rotalar](/workers/configuration/routing/routes/) dokümantasyonuna bakın.
   :::

[Projenizi yapılandırma](/workers/wrangler/configuration/) hakkında daha fazla bilgi edinin.
