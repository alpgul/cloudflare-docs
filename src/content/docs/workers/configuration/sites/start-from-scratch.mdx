Bu rehber, sıfırdan yeni bir Workers Sites projesine nasıl hızlı başlanacağını gösterir.

## Başlangıç

1. En son [git](https://git-scm.com/downloads) ve [Node.js](https://nodejs.org/en/download/) sürümlerinin yüklü olduğundan emin olun.

2. Terminalinizde `worker-sites-template` başlangıç deposunu klonlayın.
   Aşağıdaki örnek `my-site` adında bir proje oluşturur:

   ```sh
   git clone --depth=1 --branch=wrangler2 https://github.com/cloudflare/worker-sites-template my-site
   ```

3. Tüm bağımlılıkları yüklemek için `npm install` çalıştırın.

4. [`wrangler dev`](/workers/wrangler/commands/#dev) komutunu çalıştırarak sitenizi önizleyebilirsiniz:

   ```sh
   wrangler dev
   ```

5. Sitenizi Cloudflare'e dağıtın:

   ```sh
   npx wrangler deploy
   ```

## Proje düzeni

Şablon projesi aşağıdaki dosya ve dizinleri içerir:

- `public`: Projenizin statik varlıkları. Varsayılan olarak bir `index.html` ve `favicon.ico` içerir.
- `src`: Varlıklarınızı sunmak için yapılandırılmış Worker. Bunu düzenlemeniz gerekmez ancak nasıl çalıştığını görmek veya Worker'ınıza daha fazla işlevsellik eklemek istiyorsanız `src/index.ts`'yi düzenleyebilirsiniz.
- `wrangler.jsonc`: Proje yapılandırmasını içeren dosya.
  `bucket` özelliği Wrangler'a statik varlıkları nerede bulacağını söyler (örneğin `site = { bucket = "./public" }`).
- `package.json`/`package-lock.json`: gerekli Node.js bağımlılıklarını tanımlar.

## `wrangler.jsonc` dosyasını özelleştirin:

- `name` özelliğini projenizin adına değiştirin:

  <WranglerConfig>

  ```toml
  name = "my-site"
  ```

  </WranglerConfig>

- En son Workers özelliklerine erişmek için `compatibility_date`'i bugünün tarihine güncellemeyi düşünün:

  <WranglerConfig>

  ```toml
  compatibility_date = "yyyy-mm-dd"
  ```

  </WranglerConfig>

- Sitenizi sahip olduğunuz ve zaten Cloudflare zone olarak eklediğiniz [özel alana](/workers/configuration/routing/custom-domains/) dağıtın:

  <WranglerConfig>

  ```toml
  route = "https://example.com/*"
  ```

  </WranglerConfig>

  :::note

  `route`'u doğru şekilde yapılandırmak için [Rotalar](/workers/configuration/routing/routes/) dokümantasyonuna bakın.
  :::

[Projenizi yapılandırma](/workers/wrangler/configuration/) hakkında daha fazla bilgi edinin.
