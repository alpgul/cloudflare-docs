## Arka Plan

Gizli anahtarlar, Worker'ınıza şifrelenmiş metin değerleri eklemenize olanak tanıyan bir bağlama türüdür. Gizli anahtarlar API anahtarları ve kimlik doğrulama token'ları gibi hassas bilgileri saklamak için kullanılır. Gizli anahtarlar, Worker'ınızın [`fetch` olay handler'ına](/workers/runtime-apis/handlers/fetch/) geçirilen [`env` parametresinde](/workers/runtime-apis/handlers/fetch/#parameters) programatik olarak kullanılabilir ve Node.js uyumluluğunu destekleyen Worker'larda [`process.env`](/workers/configuration/environment-variables) aracılığıyla da erişilebilir.

## Worker'larla gizli anahtarlarınıza erişin

Gizli anahtarlara, diğer [ortam değişkenleri](/workers/configuration/environment-variables/) gibi Worker'lardan erişebilirsiniz. Örneğin, `DB_CONNECTION_STRING` gizli anahtarı verildiğinde, Worker kodunuzda buna erişebilirsiniz:

```js title="index.js"
import postgres from "postgres";

export default {
	async fetch(request, env, ctx) {
		const sql = postgres(env.DB_CONNECTION_STRING);

		const result = await sql`SELECT * FROM products;`;

		return new Response(JSON.stringify(result), {
			headers: { "Content-Type": "application/json" },
		});
	},
};
```

:::note[Gizli Anahtarlar Deposu (beta)]
Bu sayfada açıklanan gizli anahtarlar Worker başına tanımlanır ve yönetilir. Hesap düzeyinde gizli anahtarlar kullanmak istiyorsanız, [Gizli Anahtarlar Deposu](/secrets-store/)'na bakın. Hesap düzeyinde gizli anahtarlar Worker'ınızda [Gizli Anahtarlar Deposu bağlaması](/secrets-store/integrations/workers/) olarak yapılandırılır.
:::

## Dağıtılmış Worker'larda gizli anahtarlar

### Projenize gizli anahtar ekleme

#### Wrangler ile

Gizli anahtarlar [`wrangler secret put`](/workers/wrangler/commands/#secret) veya [`wrangler versions secret put`](/workers/wrangler/commands/#secret-put) komutları aracılığıyla eklenebilir.

`wrangler secret put` Worker'ın yeni bir sürümünü oluşturur ve hemen dağıtır.

```sh
npx wrangler secret put <KEY>
```

[Kademeli dağıtımlar](/workers/configuration/versions-and-deployments/gradual-deployments/) kullanıyorsanız, bunun yerine `wrangler versions secret put` komutunu kullanın. Bu yalnızca Worker'ın yeni bir sürümünü oluşturacak, daha sonra [`wrangler versions deploy`](/workers/wrangler/commands/#deploy-2) kullanılarak dağıtılabilir.

:::note
3.73.0'dan önceki Wrangler sürümleri `--x-versions` bayrağını belirtmenizi gerektirir.
:::

```sh
npx wrangler versions secret put <KEY>
```

#### Dashboard ile

Dashboard aracılığıyla gizli anahtar eklemek için:
1. Cloudflare dashboard'da **Workers & Pages** sayfasına gidin.

   <DashButton url="/?to=/:account/workers-and-pages" />

2. **Overview**'da Worker'ınızı seçin > **Settings**.
3. **Variables and Secrets** altında **Add**'i seçin.
4. **Secret** türünü seçin, **Variable name** girin ve **Value**'sunu girin. Bu gizli anahtar Worker'ınız için kullanılabilir hale gelecek ancak değer Wrangler ve dashboard'da gizli kalacaktır.
5. (İsteğe bağlı) Daha fazla gizli anahtar eklemek için **Add variable**'ı seçin.
6. Değişikliklerinizi uygulamak için **Deploy**'u seçin.

### Projenizden gizli anahtarları silme

#### Wrangler ile

Gizli anahtarlar [`wrangler secret delete`](/workers/wrangler/commands/#delete-1) veya [`wrangler versions secret delete`](/workers/wrangler/commands/#secret-delete) komutları aracılığıyla silinebilir.

`wrangler secret delete` Worker'ın yeni bir sürümünü oluşturur ve hemen dağıtır.

```sh
npx wrangler secret delete <KEY>
```

[Kademeli dağıtımlar](/workers/configuration/versions-and-deployments/gradual-deployments/) kullanıyorsanız, bunun yerine `wrangler versions secret delete` komutunu kullanın. Bu yalnızca Worker'ın yeni bir sürümünü oluşturacak, daha sonra [`wrangler versions deploy`](/workers/wrangler/commands/#deploy-2) kullanılarak dağıtılabilir.

```sh
npx wrangler versions secret delete <KEY>
```

#### Dashboard ile

Dashboard aracılığıyla Worker projenizden gizli anahtar silmek için:

1. Cloudflare dashboard'da **Workers & Pages** sayfasına gidin.

   <DashButton url="/?to=/:account/workers-and-pages" />

2. **Overview**'da Worker'ınızı seçin > **Settings**.
3. **Variables and Secrets** altında **Edit**'i seçin.
4. **Edit** çekmecesinde, silmek istediğiniz gizli anahtarın yanındaki **X**'i seçin.
5. Değişikliklerinizi uygulamak için **Deploy**'u seçin.
6. (İsteğe bağlı) Edit çekmecesini kullanmak yerine, gizli anahtarın yanındaki silme simgesini tıklayabilirsiniz.
