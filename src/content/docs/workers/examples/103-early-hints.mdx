Bu, GitHub hesabınızda bir depo oluşturur ve uygulamayı Cloudflare Workers'a dağıtır.

`103` Early Hints, içerik teslimatını hızlandırmak için tasarlanmış bir HTTP durum kodudur. Etkinleştirildiğinde, Cloudflare HTML sayfalarından preload ve/veya preconnect ile işaretlenmiş `Link` başlıklarını önbelleğe alabilir ve bunları origin sunucusuna ulaşmadan önce `103` Early Hints yanıtında sunabilir. Tarayıcılar, origin'in nihai yanıtını beklerken bağlantılı varlıkları getirmek için bu ipuçlarını kullanabilir, bu da sayfa yükleme hızlarını önemli ölçüde artırır.

Early Hints'in zone'unuzda etkinleştirildiğinden emin olmak için:

<Steps>
1. Cloudflare dashboard'da **Speed settings** sayfasına gidin.

   <DashButton url="/?to=/:account/:zone/speed/optimization" />

2. **Content Optimization**'a gidin.
3. **Early Hints** geçişini açık konuma getirin.
</Steps>

Sayfa yükleme sürelerinizi hızlandırmak için zone'unuzda çalışan bir Worker'dan `Link` başlıkları döndürebilirsiniz.

<Tabs syncKey="workersExamples"> <TabItem label="JavaScript" icon="seti:javascript">

```js
const CSS = "body { color: red; }";
const HTML = `
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Early Hints test</title>
    <link rel="stylesheet" href="/test.css">
</head>
<body>
    <h1>Early Hints test page</h1>
</body>
</html>
`;

export default {
	async fetch(req) {
		// Eğer istek test.css için ise, ham CSS'i sun
		if (/test\.css$/.test(req.url)) {
			return new Response(CSS, {
				headers: {
					"content-type": "text/css",
				},
			});
		} else {
			// CSS dosyası için Early Hints kullanarak ham HTML'i sun
			return new Response(HTML, {
				headers: {
					"content-type": "text/html",
					link: "</test.css>; rel=preload; as=style",
				},
			});
		}
	},
};
```

</TabItem> <TabItem label="Python" icon="seti:python">

```py
import re
from workers import Response, WorkerEntrypoint

CSS = "body { color: red; }"
HTML = """
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Early Hints test</title>
    <link rel="stylesheet" href="/test.css">
</head>
<body>
    <h1>Early Hints test page</h1>
</body>
</html>
"""

class Default(WorkerEntrypoint):
    async def fetch(self, request):
        if re.search("test.css", request.url):
            headers = {"content-type": "text/css"}
            return Response(CSS, headers=headers)
        else:
            headers = {"content-type": "text/html","link": "</test.css>; rel=preload; as=style"}
        return Response(HTML, headers=headers)
```

</TabItem> <TabItem label="Hono" icon="seti:typescript">

```ts
import { Hono } from "hono";

const app = new Hono();

const CSS = "body { color: red; }";
const HTML = `
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Early Hints test</title>
    <link rel="stylesheet" href="/test.css">
</head>
<body>
    <h1>Early Hints test page</h1>
</body>
</html>
`;

// CSS dosyasını sun
app.get("/test.css", (c) => {
	return c.body(CSS, {
		headers: {
			"content-type": "text/css",
		},
	});
});

// Early hints ile HTML'i sun
app.get("*", (c) => {
	return c.html(HTML, {
		headers: {
			link: "</test.css>; rel=preload; as=style",
		},
	});
});

export default app;
```
