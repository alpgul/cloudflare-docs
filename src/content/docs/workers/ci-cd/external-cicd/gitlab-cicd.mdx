[GitLab CI/CD](https://docs.gitlab.com/ee/ci/pipelines/index.html) ile Workers'ları dağıtabilirsiniz. GitHub Actions iş akışınızı nasıl kurabileceğiniz aşağıda verilmiştir.

## 1. Kimlik doğrulama

Wrangler'ı yerel olarak çalıştırırken, Cloudflare API'sine kimlik doğrulama [`wrangler login`](/workers/wrangler/commands/#login) komutu aracılığıyla gerçekleşir ve bu da etkileşimli bir kimlik doğrulama akışını başlatır. CI/CD ortamları etkileşimli olmadığından, Wrangler Cloudflare API'si ile kimlik doğrulaması için bir [Cloudflare API token](/fundamentals/api/get-started/create-token/) ve [hesap ID](/fundamentals/account/find-account-and-zone-ids/) gerektirir.

### Cloudflare hesap ID

Cloudflare hesap ID'nizi bulmak için [Hesap ve zone ID'lerini bulma](/fundamentals/account/find-account-and-zone-ids/)'ya bakın.

### API token

CI işinizde Wrangler'ı kimlik doğrulaması için bir API token oluşturmak için:

1. Cloudflare dashboard'da **Account API tokens** sayfasına gidin.

   <DashButton url="/?to=/:account/api-tokens" />

2. **Create Token** > **Edit Cloudflare Workers**'ı bulun > **Use Template**'i seçin.
3. Token adınızı özelleştirin.
4. Token'ınızı kapsamını belirleyin.

Oluşturulan API token'ın erişimi olacağı hesap ve zone kaynaklarını seçmeniz gerekecek. Token'ınızın erişimini sınırlamak için bunları mümkün olduğunca daraltmanızı öneririz. Örneğin, üç farklı Cloudflare hesabına erişiminiz varsa, oluşturulan API token'ı yalnızca Worker dağıtacağınız hesaba kısıtlamalısınız.

## 2. CI kurulumu

Wrangler'ı CI/CD ortamınızda çalıştırma yöntemi, projenizin özel kurulumuna bağlı olacaktır (GitHub Actions/Jenkins/GitLab kullanıp kullanmadığınız veya tamamen farklı bir şey kullanıp kullanmadığınız).

CI'nizi kurmak için:

1. CI platformunuza gidin ve aşağıdakileri sırlar olarak ekleyin:

- `CLOUDFLARE_ACCOUNT_ID`: Worker'ınızı dağıtmak istediğiniz hesap için [Cloudflare hesap ID](#cloudflare-account-id)'sine ayarlayın.
- `CLOUDFLARE_API_TOKEN`: [Oluşturduğunuz Cloudflare API token](#api-token)'ına ayarlayın.

:::caution

`CLOUDFLARE_API_TOKEN`'ın değerini deponuzda saklamayın, çünkü bu hesabınızda Workers'ları dağıtma erişimi verir. Bunun yerine, CI/CD sağlayıcınızın sırları saklama desteğini kullanmalısınız.
:::

2. Worker'ı dağıtmaktan sorumlu olacak bir iş akışı oluşturun. Bu iş akışı `wrangler deploy` çalıştırmalıdır. Aşağıdaki bölümde örnek bir [GitHub Actions](https://docs.github.com/en/actions/using-workflows/about-workflows) iş akışını inceleyin.

### GitLab Pipelines

Örnek bir pipeline için [GitLab'ın blog'una](https://about.gitlab.com/blog/2022/11/21/deploy-remix-with-gitlab-and-cloudflare/) bakın. `script` anahtarı altında `npm run deploy`'u [`npx wrangler deploy`](/workers/wrangler/commands/#deploy) ile değiştirin.
