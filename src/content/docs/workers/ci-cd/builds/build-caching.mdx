Proje genelinde paylaşılan önbellek ile build'ler arasında bağımlılıkları ve build çıktılarını önbellekleyerek Workers build sürelerini iyileştirin.

Workers projenizde build önbellekleme etkinleştirildikten sonra gerçekleşen ilk build, ilgili yapıtları önbelleğe kaydedecektir. Her sonraki build, aksi yapılandırılmadıkça önbellekten geri yüklenecektir.

## Build önbelleği hakkında

Etkinleştirildiğinde, build önbellekleme projenin `package.json` dosyasından hangi paket yöneticisi ve framework'ü kullandığını otomatik olarak algılayacak ve build için veriyi buna göre önbellekleyecektir.

Aşağıdaki tablo, hangi paket yöneticilerinin ve framework'lerin sırasıyla bağımlılık ve build çıktısı önbellekleme için desteklendiğini göstermektedir.

### Paket yöneticileri

Workers build önbelleği aşağıdaki paket yöneticilerinin global önbellek dizinlerini önbellekleyecektir:

| Paket Yöneticisi                | Önbelleklenen Dizinler |
| -------------------------------- | ---------------------- |
| [npm](https://www.npmjs.com/)   | `.npm`                 |
| [yarn](https://yarnpkg.com/)    | `.cache/yarn`          |
| [pnpm](https://pnpm.io/)        | `.pnpm-store`          |
| [bun](https://bun.sh/)          | `.bun/install/cache`   |

### Framework'ler

Bazı framework'ler, genellikle build zamanında ara build çıktıları veya bağımlılıklarla framework tarafından doldurulan bir önbellek dizini sağlar. Workers Builds, kullandığınız framework'ü otomatik olarak algılayacak ve sonraki build'lerde yeniden kullanım için bu dizini önbellekleyecektir.

Aşağıdaki framework'ler build çıktısı önbellekleme destekler:

| Framework  | Önbelleklenen Dizinler                        |
| ---------- | ---------------------------------------------- |
| Astro      | `node_modules/.astro`                          |
| Docusaurus | `node_modules/.cache`, `.docusaurus`, `build`  |
| Eleventy   | `.cache`                                       |
| Gatsby     | `.cache`, `public`                            |
| Next.js    | `.next/cache`                                  |
| Nuxt       | `node_modules/.cache/nuxt`                     |

:::note
[Statik varlıklar](/workers/static-assets/) ve [framework'ler](/workers/framework-guides/) artık Cloudflare Workers'da desteklenmektedir.
:::

### Limitler

Build önbellekleme için aşağıdaki limitler uygulanır:

- **Saklama**: Önbellek son okuma tarihinden 7 gün sonra temizlenir. Okunmamış önbellek yapıtları oluşturulduktan 7 gün sonra temizlenir.
- **Depolama**: Her projeye 10 GB ayrılır. Proje önbelleği bu limiti aşarsa, proje otomatik olarak en az yakın zamanda okunan yapıtları silmeye başlayacaktır.

## Build önbelleğini etkinleştir

Build önbellekleme etkinleştirmek için:

1. Dashboard'da [Workers & Pages Overview](https://dash.cloudflare.com)'a gidin.
2. Workers projenizi bulun.
3. **Settings** > **Build** > **Build cache**'e gidin.
4. Build önbellekleme açmak için **Enable**'ı seçin.

## Build önbelleğini temizle

Build önbelleği gerektiğinde, örneğin build sorunlarını ayıklarken bir proje için temizlenebilir. Build önbelleğini temizlemek için:

1. Dashboard'da [Workers & Pages Overview](https://dash.cloudflare.com)'a gidin.
2. Workers projenizi bulun.
3. **Settings** > **Build** > **Build cache**'e gidin.
4. Build önbelleğini temizlemek için **Clear Cache**'i seçin.
