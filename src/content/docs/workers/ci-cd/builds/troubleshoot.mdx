Bu rehber, build hatalarını nasıl tanımlayacağınızı ve çözeceğinizi, ayrıca Workers Builds dağıtım sürecindeki yaygın sorunları nasıl çözeceğinizi açıklar.

Build geçmişinizi görüntülemek için Cloudflare dashboard'da Worker projenize gidin, **Deployment**'ı seçin, sayfanın alt kısmında **View Build History**'yi seçin ve görüntülemek istediğiniz build'i seçin. Bir build'i yeniden denemek için build'in yanındaki üç noktayı seçin ve **Retry build**'i seçin. Alternatif olarak, Build Details sayfasında **Retry build**'i seçebilirsiniz.

## Bilinen sorunlar veya sınırlamalar

Build loglarında ortaya çıkabilecek yaygın build hataları veya genel sorunlar ve bunları nasıl çözebileceğiniz aşağıda verilmiştir.

### Workers ad gereksinimi

`✘ [ERROR] The name in your wrangler.toml file (<Worker name>) must match the name of your Worker. Please update the name field in your wrangler.toml file.`

Git deposunu Workers projenize bağlarken, Cloudflare dashboard'da belirtilen Worker adı, belirtilen kök dizindeki wrangler.toml dosyasındaki `name` argümanıyla eşleşmelidir. Eşleşmiyorsa, wrangler.toml dosyanızdaki name alanını dashboard'daki Worker adıyla eşleşecek şekilde güncelleyin.

Build sistemi, hangi Worker'ın Cloudflare'in global ağına dağıtılacağını belirlemek için wrangler.toml'daki `name` argümanını kullanır. Bu gereksinim, dashboard'daki Worker adı ile dağıtılan Worker arasında tutarlılık sağlar.

:::note
Bu, Worker adı `-<env_name>` sonekinden önce wrangler.toml'daki adla eşleşiyorsa [Wrangler Environments](/workers/wrangler/environments/) için geçerli değildir.

Örneğin, dashboard'da `my-worker-staging` adında bir Worker, `name = my-worker` ve `[env.staging]` argümanları içeren bir wrangler.toml içeren bir depodan `npx wrangler deploy --env staging` deploy komutu kullanılarak dağıtılabilir.

Wrangler v3 ve üzerinde, Workers Builds `WRANGLER_CI_OVERRIDE_NAME` ortam değişkeni ile geçersiz kılarak bağlı Worker'ın adını otomatik olarak eşleştirir.
:::

### Eksik wrangler.toml

`✘ [ERROR] Missing entry-point: The entry-point should be specified via the command line (e.g. wrangler deploy path/to/script) or the main config field.`

Bu hatayı görüyorsanız, kök dizinde wrangler.toml eksik olabilir. Kök dizini güncellemek için **Settings** > **Build** > **Build Configuration**'a gidin veya belirtilen dizine bir [wrangler.toml](/workers/wrangler/configuration/) ekleyin.

### Yanlış account_id

`Could not route to /client/v4/accounts/<Account ID>/workers/services/<Worker name>, perhaps your object identifier is invalid? [code: 7003]`

Bu hatayı görüyorsanız, wrangler.toml muhtemelen farklı bir hesap için `account_id` içeriyor. `account_id` argümanını kaldırın veya **Workers & Pages Overview** altında **Account Details**'te bulunan hesabınızın `account_id`'si ile güncelleyin.

### Eski API token

` Failed: The build token selected for this build has been deleted or rolled and cannot be used for this build. Please update your build token in the Worker Builds settings and retry the build.`

Build Configuration ayarlarındaki API Token açılır menüsü, düzenlenmiş, silinmiş veya yenilenmiş eski token'ları gösterebilir. Eski token nedeniyle bir hata ile karşılaşırsanız, yeni bir API Token oluşturun ve build için seçin.

### Build zaman aşımı

`Build was timed out`

Maksimum build süresi 20 dakikadır. Bir build bu süreyi aşarsa, build sonlandırılacak ve yukarıdaki hata logu gösterilecektir. Daha fazla ayrıntı için [Workers Builds limitleri](/workers/ci-cd/builds/limits-and-pricing/)'ne bakın.

### Git entegrasyon sorunları

Git entegrasyonunuzla ilgili hatalarla karşılaşıyorsanız, Cloudflare'den [GitHub](/workers/ci-cd/builds/git-integration/github-integration/#removing-access) veya [GitLab](/workers/ci-cd/builds/git-integration/gitlab-integration/#removing-access) entegrasyonunuza erişimi kaldırmayı, ardından [GitHub](/workers/ci-cd/builds/git-integration/github-integration/#reinstall-a-git-integration) veya [GitLab](/workers/ci-cd/builds/git-integration/gitlab-integration/#reinstall-a-git-integration) entegrasyonunu yeniden kurmayı deneyebilirsiniz.
