Git deposunu Workers'a bağladığınızda, üretim git dalında yapılan commit'ler Workers Build üretecektir. [Önizleme URL'leri](/workers/configuration/previews/) ve [pull request yorumları](/workers/ci-cd/builds/git-integration/github-integration/#pull-request-comment) avantajlarından yararlanmak istiyorsanız, deponuzun tüm dallarında build tetiklemek için ek olarak "üretim dışı dal build'leri"ni etkinleştirebilirsiniz.

## Üretim dalını değiştir

Projenizin üretim dalını değiştirmek için:

1. **Overview**'da Workers projenizi seçin.
2. **Settings** > **Build** > **Branch control**'a gidin. Workers, git deponuzun varsayılan dalına varsayılan olarak ayarlanacaktır, ancak bu açılır menüden değiştirilebilir.

Bu dala yapılan her push olayı bir build tetikleyecek ve [build komutu](/workers/ci-cd/builds/configuration/#build-command)'nu, ardından [deploy komutu](/workers/ci-cd/builds/configuration/#deploy-command)'nu çalıştıracaktır.

## Üretim dışı dal build'lerini yapılandır

Üretim dışı dal build'lerini etkinleştirmek veya devre dışı bırakmak için:

1. **Overview**'da Workers projenizi seçin.
2. **Settings** > **Build** > **Branch control**'a gidin. **Pull Request Previews** altındaki düğme, üretim dışı dallar için build'leri etkinleştirmenize veya devre dışı bırakmanıza olanak tanır.

Etkinleştirildiğinde, üretim dışı bir dala yapılan her push olayı bir build tetikleyecek ve [build komutu](/workers/ci-cd/builds/configuration/#build-command)'nu, ardından [üretim dışı dal deploy komutu](/workers/ci-cd/builds/configuration/#non-production-branch-deploy-command)'nu çalıştıracaktır.
