Cloudflare [Git entegrasyonu](/workers/ci-cd/builds/git-integration/), yeni veya mevcut bir Worker'ı GitHub veya GitLab deposuna bağlamanıza olanak tanır ve push üzerine Worker'ınız için otomatik build'ler ve dağıtımlar sağlar.

## Başlayın

### Yeni bir Worker bağlayın

Yeni bir Worker oluşturmak ve onu GitHub veya GitLab deposuna bağlamak için:
1. Cloudflare kontrol panelinde **Workers & Pages** sayfasına gidin.

   <DashButton url="/?to=/:account/workers-and-pages" />

2. **Create application**'ı seçin.
3. **Import a repository** yanındaki **Get started**'ı seçin.
4. **Import a repository** altında bir **Git account** seçin.
5. Listeden import etmek istediğiniz deposu seçin. Sonuçları daraltmak için arama çubuğunu da kullanabilirsiniz.
6. Projenizi yapılandırın ve **Save and Deploy**'u seçin.
7. Worker'ınızı sağlanan [`workers.dev`](/workers/configuration/routing/workers-dev/) alt etki alanında önizleyin.

### Mevcut bir Worker'ı bağlayın

Mevcut bir Worker'ı GitHub veya GitLab deposuna bağlamak için:
1. Cloudflare kontrol panelinde **Workers & Pages** sayfasına gidin.

   <DashButton url="/?to=/:account/workers-and-pages" />

2. Depoya bağlamak istediğiniz Worker'ı seçin.
3. **Settings** ve ardından **Builds**'ı seçin.
4. **Connect**'i seçin ve deposunu Worker'ınıza bağlamak ve [build ayarlarınızı](/workers/ci-cd/builds/configuration/) yapılandırmak için istemleri takip edin.
5. Build'i tetiklemek ve Worker'ınıza dağıtmak için Git deponuza bir commit push edin.

:::caution

Bir depoyu Workers projesine bağlarken, Cloudflare kontrol panelindeki Worker adı, belirtilen kök dizindeki wrangler.toml dosyasındaki `name` ile eşleşmelidir, aksi takdirde build başarısız olur. Bu, depodan dağıtılan Worker'ın Cloudflare kontrol panelinde kayıtlı Worker ile tutarlı olmasını sağlar. Ayrıntılar için [Workers ad gereksinimi](/workers/ci-cd/builds/troubleshoot/#workers-name-requirement)'ne bakın.

:::

## Build ve önizleme URL'sini görüntüleyin

Worker'ınızın **Deployments** sekmesinin alt kısmındaki **View build history**'ye giderek bir build'in durumunu ve build loglarını izleyebilirsiniz.

Build başarılıysa, Version History altında oluşturulan yeni [versiyon](/workers/configuration/versions-and-deployments/) ile ilişkili **View build**'i seçerek build ayrıntılarını görüntüleyebilirsiniz. Orada Version ID altında versiyon tarafından oluşturulan [önizleme URL'sini](/workers/configuration/previews/) de bulacaksınız.

:::note[Builds, versiyonlar, dağıtımlar]

Bir build başarılı olursa, versiyon olarak yüklenir. Build dağıtım için yapılandırılmışsa (örneğin, `wrangler deploy` deploy komutu olarak ayarlanmışsa), yüklenen versiyon otomatik olarak Active Deployment'a terfi ettirilir.

:::

## Build'leri bağlantısını kesme

Bir Worker'ı GitHub veya GitLab deposundan bağlantısını kesmek için:
1. Cloudflare kontrol panelinde **Workers & Pages** sayfasına gidin.

   <DashButton url="/?to=/:account/workers-and-pages" />

2. Depodan bağlantısını kesmek istediğiniz Worker'ı seçin.
4. **Settings** ve ardından **Builds**'ı seçin.
5. **Disconnect**'i seçin.

Worker'ınız için farklı bir depoya geçmek istiyorsanız, önce build'leri devre dışı bırakmalı, ardından yeni deposu seçmek için yeniden bağlanmalısınız.

Build'lerin otomatik olarak çalışmasına ve [versiyonlar](/workers/configuration/versions-and-deployments/) olarak kaydedilmesine izin verirken otomatik dağıtımları devre dışı bırakmak için (bunları aktif dağıtıma terfi ettirmeden), deploy komutunuzu şu şekilde güncelleyin: `npx wrangler versions upload`.
