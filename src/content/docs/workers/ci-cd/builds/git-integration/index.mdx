Cloudflare, [GitHub](/workers/ci-cd/builds/git-integration/github-integration/) ve [GitLab](/workers/ci-cd/builds/git-integration/gitlab-integration/) deponuzu Cloudflare Worker'ınıza bağlamayı destekler ve her değişiklik push ettiğinizde kodunuzu otomatik olarak dağıtır.

Git entegrasyonu eklemek ayrıca [pull request yorumları](/workers/ci-cd/builds/git-integration/github-integration/#pull-request-comment), [check runs](/workers/ci-cd/builds/git-integration/github-integration/#check-run) veya [commit statuses](/workers/ci-cd/builds/git-integration/gitlab-integration/#commit-status) kullanarak build durumlarını doğrudan Git sağlayıcınızda izlemenize olanak tanır, böylece iş akışınızdan ayrılmadan dağıtımları yönetebilirsiniz.

## Desteklenen Git Sağlayıcıları

Cloudflare, Cloudflare Workers'ı GitHub ve GitLab depolarınıza bağlamayı destekler. Workers Builds şu anda self-hosted GitHub veya GitLab örneklerini bağlamayı desteklememektedir.

Farklı bir Git sağlayıcısı (örn. Bitbucket) kullanıyorsanız, [harici CI/CD sağlayıcısı (örn. GitHub Actions)](/workers/ci-cd/external-cicd/) kullanabilir ve [Wrangler CLI](/workers/wrangler/commands/#deploy) ile dağıtım yapabilirsiniz.

## Git Entegrasyonu Ekle

Workers Builds, self-hosted _olmayan_ bireysel ve organizasyon hesapları dahil olmak üzere GitHub ve GitLab hesaplarıyla doğrudan entegrasyon sağlar.

Cloudflare hesabınıza bağlı Git hesabınız yoksa, [depo bağlarken](/workers/ci-cd/builds/#get-started) ilk kez veya yeni Git hesabı eklerken GitHub veya GitLab kurulumu yapmanız istenecektir. İstemleri takip edin ve Cloudflare Git entegrasyonunu yetkilendirin.

![Git sağlayıcıları](~/assets/images/workers/platform/ci-cd/workers-git-provider.png)

Git entegrasyonunuzun kurulup kurulmadığını kontrol etmek için aşağıdaki sayfaları kontrol edebilirsiniz:

- [GitHub Applications sayfası](https://github.com/settings/installations) (bir organizasyonda iseniz, GitHub organizasyon ayarlarınıza erişmek için **Switch settings context**'i seçin)
- [GitLab Authorized Applications sayfası](https://gitlab.com/-/profile/applications)

Organizasyon hesaplarına erişim sağlama ayrıntıları için [GitHub organizasyon erişimi](/workers/ci-cd/builds/git-integration/github-integration/#organizational-access) ve [GitLab organizasyon erişimi](/workers/ci-cd/builds/git-integration/gitlab-integration/#organizational-access)'ne bakın.

## Git Entegrasyonunu Yönet

Git kurulumunuzu yönetmek için:

<Steps>
1. Cloudflare dashboard'da **Workers & Pages** sayfasına gidin.

   <DashButton url="/?to=/:account/workers-and-pages" />

2. Worker'ınızı seçin.
3. **Settings** > **Builds**'e gidin.
4. **Git Repository** altında **Manage**'i seçin.
</Steps>

Bu, depo erişimini yönetmek veya kurulum sorunlarını yeniden kurarak gidermek için yararlı olabilir. Daha fazla ayrıntı için kurulumunuzu nasıl yöneteceğiniz konusunda [GitHub](/workers/ci-cd/builds/git-integration/github-integration) ve [GitLab](/workers/ci-cd/builds/git-integration/gitlab-integration) rehberlerine bakın.
