Cloudflare, GitHub deponuzu Cloudflare Worker'ınıza bağlamayı destekler ve her değişiklik push ettiğinizde kodunuzu otomatik olarak dağıtır.

## Özellikler

Otomatik build'ler ve dağıtımların ötesinde, Cloudflare GitHub entegrasyonu build'leri doğrudan GitHub'da izlemenize olanak tanır, böylece iş akışınızdan ayrılmadan bilgilendirilirsiniz.

### Pull request yorumu

Bir commit pull request'te ise, Cloudflare otomatik olarak pull request'e build durumuyla ilgili bir yorum gönderir.

![GitHub pull request yorumu](~/assets/images/workers/platform/ci-cd/github-pull-request-comment.png)

`wrangler versions upload` gerçekleştiren herhangi bir build için [önizleme URL'si](/workers/configuration/previews/) sağlanacaktır. Bu, pull request'inizi gözden geçirirken özellikle yararlıdır çünkü kod değişikliklerini Worker'ınızın güncellenmiş sürümüyle birlikte karşılaştırmanıza olanak tanır.

Yorum geçmişi, PR açıkken daha önce tamamlanan build'leri gösterir.

![GitHub pull request yorum geçmişi](~/assets/images/workers/platform/ci-cd/github-pull-request-comment-history.png)

### Check run

Bir veya birden fazla Worker'ı bir depoya bağladıysanız (yani [monorepo](/workers/ci-cd/builds/advanced-setups/#monorepos)), GitHub deponuz içinde [GitHub check runs](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/collaborating-on-repositories-with-code-quality-features/about-status-checks#checks) aracılığıyla her build'in durumunu kontrol edebilirsiniz.

GitHub deponuz içindeki commit'in yanındaki durum simgesini seçerek check'leri görebilirsiniz. Aşağıdaki örnekte, check run'un sonuçlarını görmek için yeşil onay işaretini seçebilirsiniz.

![GitHub durum](~/assets/images/workers/platform/ci-cd/gh-status-check-runs.png)

Check run'lar deponuzda aşağıdaki gibi görünecektir. Her check ile ilişkili build'i (Build ID) ve projeyi (Script) görüntülemek için **Details**'i seçebilirsiniz.

![GitHub check run'lar](~/assets/images/workers/platform/ci-cd/workers-builds-gh-check-runs.png)

[Build watch paths](/workers/ci-cd/builds/build-watch-paths/) kullanırken, yalnızca build tetikleyen projelerin check run oluşturacağını unutmayın.

## Erişimi yönet

Şirketinizden veya GitHub'daki yan projenizden [Cloudflare Workers & Pages GitHub App](https://github.com/apps/cloudflare-workers-and-pages) kullanarak projeleri Cloudflare Workers'a dağıtabilirsiniz.

### Organizasyon erişimi

Cloudflare Workers'ın GitHub hesabına erişimini yetkilendirirken, bireysel hesabınıza veya GitHub'da ait olduğunuz bir organizasyona erişim belirtebilirsiniz.

Cloudflare Workers kurulumunu bir organizasyona eklemek için, kullanıcı hesabınızın sahip olması veya organizasyon içinde uygun role sahip olması gerekir (yani GitHub Apps Manager rolü). Bu roller hakkında daha fazla bilgi [GitHub'ın dokümantasyonunda](https://docs.github.com/en/organizations/managing-peoples-access-to-your-organization-with-roles/roles-in-an-organization#github-app-managers) görülebilir.

:::caution[GitHub güvenlik değerlendirmesi]

Bir GitHub hesabı yalnızca bir Cloudflare hesabını işaret etmelidir. Organizasyonunuz için Cloudflare'i GitHub ile kuruyorsanız, Cloudflare uygulamanın kapsamını yalnızca Pages ile build etmeyi planladığınız depoları içerecek şekilde sınırlamanızı önerir. Bu izinleri değiştirmek için GitHub'da [Applications sayfasına](https://github.com/settings/installations) gidin ve GitHub organizasyon ayarlarınıza erişmek için **Switch settings context**'i seçin. Ardından **Cloudflare Workers & Pages** > **Repository access** için **Only select repositories**'i seçin > depolarınızı seçin.

:::

### Erişimi kaldır

GitHub'da [Applications sayfasına](https://github.com/settings/installations) giderek Cloudflare Workers'ın GitHub deponuz veya hesabınıza erişimini kaldırabilirsiniz (bir organizasyonda iseniz, GitHub organizasyon ayarlarınıza erişmek için Switch settings context'i seçin). GitHub App'i Cloudflare Workers ve Pages olarak adlandırılır ve Workers ve Pages projeleri arasında paylaşılır.

#### Cloudflare'in GitHub deposuna erişimini kaldır

Tek bir GitHub deposuna erişimi kaldırmak için **Repository access**'e gidebilirsiniz. **Only select repositories** seçeneğini seçin ve Cloudflare'in erişmesini istediğiniz depoları yapılandırın.

![GitHub Depo Erişimi](~/assets/images/workers/platform/ci-cd/github-repository-access.png)

#### Cloudflare'in tüm GitHub hesabına erişimini kaldır

Cloudflare Workers ve Pages'in tüm Git hesabınıza erişimini kaldırmak için **Uninstall "Cloudflare Workers and Pages"**'e gidebilir, ardından **Uninstall**'i seçebilirsiniz. Cloudflare Workers ve Pages uygulamasına erişimi kaldırmak, Cloudflare'in o GitHub hesabından _tüm depolara_ erişimini iptal edecektir. Yalnızca otomatik build'leri ve dağıtımları devre dışı bırakmak istiyorsanız, [Build'i Devre Dışı Bırak](/workers/ci-cd/builds/#disconnecting-builds) talimatlarını takip edin.

GitHub'a erişimi kaldırmanın, o depolara bağlı Workers ve Pages projeleri için yeni build'leri devre dışı bırakacağını, ancak önceki dağıtımlarınızın Cloudflare Workers tarafından barındırılmaya devam edeceğini unutmayın.

### Cloudflare GitHub App'ini yeniden kur

Git entegrasyonu ile ilgili sorunlarla karşılaştığınızda, potansiyel sorun giderme adımlarından biri Cloudflare Pages kurulumuyla ilişkili GitHub veya GitLab uygulamasını kaldırmayı ve yeniden kurmayı denemektir. Her Git sağlayıcısı için süreç aşağıda verilmiştir.

1. GitHub'da kurulum ayarları sayfasına gidin:
   - Workers veya Pages projesi için **Settings > Builds**'e gidin ve Git Repository altında **Manage**'i seçin.
   - Alternatif olarak, Cloudflare Workers ve Pages kurulumunu bulmak için bu bağlantıları ziyaret edin ve **Configure**'u seçin:

|                  |                                                                                    |
| ---------------- | ---------------------------------------------------------------------------------- |
| **Bireysel**     | `https://github.com/settings/installations`                                        |
| **Organizasyon** | `https://github.com/organizations/<YOUR_ORGANIZATION_NAME>/settings/installations` |

2. Cloudflare Workers ve Pages GitHub App ayarları sayfasında **Uninstall "Cloudflare Workers and Pages"**'e gidin ve **Uninstall**'i seçin.
3. [**Workers & Pages** genel bakış](https://dash.cloudflare.com) sayfasına geri dönün. **Create application** > **Pages** > **Connect to Git**'i seçin.
4. **+ Add account** düğmesini seçin, eklemek istediğiniz GitHub hesabını seçin ve ardından **Install & Authorize**'u seçin.
5. GitHub hesabınız veya organizasyonunuzun hesap listesinde olduğu proje oluşturma sayfasına yönlendirilmelisiniz.
6. Daha önce bozuk olan projenizle yeni bir dağıtım yapmayı deneyin.
